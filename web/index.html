Getting started

  • Use Chrome (Web Bluetooth). Switch the robot on.
  • This page: click Connect and choose Espruino SMARTIBOT.
  • Code it: open the Web IDE with Smartibot blocks, then connect → Web Bluetooth.
  • Type commands in the IDE console (left) to test them live. Use the editor (right) and Upload for whole programs.
  • Code is lost at power-off unless you save it: save() or the IDE's "Save on send" option.
  • Only one app can be connected at a time, so disconnect the IDE before using this page.

Commands

var s = require("Smartibot");

Motors

s.setMotor(1, 0.5);  // motor 1..4, speed -1..1
s.setMotor(1, 0);    // stop

Motors 1 and 2 drive the wheels. Test which one is left.

Eye LEDs

s.setLEDs([255,0,0], [0,0,255]); // left, right [R,G,B] 0..255
s.setLEDs();                     // off
LED.write(1);                    // small blue LED

Servos

s.setServo(1, 50);   // servo 1..10, position 0..100

Buttons

BTN1.read();  // A (BTN2 = B)
setWatch(e => print(e.state), BTN1,
  { repeat: true, edge: "both" });

Timing

setTimeout(() => s.setMotor(1, 0), 1000);
var id = setInterval(fn, 500); clearInterval(id);

Expansion ports

s.E1 / s.E2 = { i2c, ad, int }: a shared I²C bus plus two GPIO pins each.

Add-on boards

Display: 16×9 colour LEDs (plug into E1)

var g = require("Smartibot-display").connect(s.E1);
g.drawString("Hi"); g.flip();

Uses the standard Graphics API. Call g.flip() to show what you drew.

Distance: laser + gesture sensors (plug into E1)

var d = require("Smartibot-distance").connect(s.E1);
d.getLeft(); d.getRight(); d.getGesture();

Uses VL53L0X time-of-flight and APDS9960 gesture sensors.

Anything else

E1/E2 are plain I²C ports, so many Espruino sensor modules work once wired.

Explore it yourself

Type these in the IDE console:

Object.keys(require("Smartibot")) // list functions
require("Smartibot").setServo     // show its code
NRF.getBattery()                  // battery voltage
process.memory()                  // free memory
  • Press Tab in the console to autocomplete.
  • Build something in Blockly, then switch to code view to see the JS it makes.
  • Anything in the Espruino reference runs on the robot, e.g. NRF.* for Bluetooth.
