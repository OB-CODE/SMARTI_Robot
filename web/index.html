Getting started

Simplified diagram: positions on your board differ. Find each group by the labels printed on it.

1. The board

The brain is a Bluetooth chip running Espruino. Everything else plugs into it through groups of pins, and each group is labelled on the board. Use the arrows to go through them one at a time.

2. Power

The battery pack plugs in here, and the switch turns the board on. The motors and servos run straight off the batteries, so weak batteries mean slow motors.

NRF.getBattery()  // battery voltage

3. Motors: M1–M4

Each motor has 2 pins. There's no + or −: the way round you plug it in only sets which way it spins. If a wheel goes backwards, swap its two wires or use a negative speed.

wirewire

Your wheels are on M1 and M2. M3 and M4 are spare.

s.setMotor(1, 0.5);  // speed -1..1

4. Servos: S1–S10

Each servo has 3 pins, one for each wire on a servo plug:

− ground
brown/black+ power
redS signal
orange/yellow

Check the board's markings for which end is ground, and plug the dark wire in on that side. If it's the wrong way round, the servo won't move.

s.setServo(1, 50);  // position 0..100

5. Add-on ports: E1 and E2

These are for add-on boards like the display and distance sensor. Each port has:

SDA SCL
I²C dataAD INT
general pins+ −
power

Both ports share one I²C bus, so the add-ons can use either. The labels on the board give the pin order.

require("Smartibot-display").connect(s.E1)

6. Buttons and lights

A and B are buttons you can read in code. The two eyes are colour LEDs. There's also a small blue LED.

BTN1.read()                      // button A
s.setLEDs([255,0,0], [0,0,255]); // eyes
  • Use Chrome (Web Bluetooth). Switch the robot on.
  • This page: click Connect and choose Espruino SMARTIBOT.
  • Code it: open the Web IDE with Smartibot blocks, then connect → Web Bluetooth.
  • Type commands in the IDE console (left) to test them live. Use the editor (right) and Upload for whole programs.
  • Code is lost at power-off unless you save it: save() or the IDE's "Save on send" option.
  • Only one app can be connected at a time, so disconnect the IDE before using this page.

Commands

var s = require("Smartibot");

Motors

s.setMotor(1, 0.5);  // motor 1..4, speed -1..1
s.setMotor(1, 0);    // stop

Motors 1 and 2 drive the wheels. Test which one is left.

Eye LEDs

// left eye, right eye: [R,G,B] 0..255
s.setLEDs([255,0,0], [0,0,255]);
s.setLEDs();    // off
LED.write(1);   // small blue LED

Servos

s.setServo(1, 50);  // servo 1..10, position 0..100

Buttons

BTN1.read();  // A (BTN2 = B)
setWatch(e => print(e.state), BTN1,
  { repeat: true, edge: "both" });

Timing

setTimeout(() => s.setMotor(1, 0), 1000);
var id = setInterval(fn, 500); clearInterval(id);

Expansion ports

s.E1 / s.E2 = { i2c, ad, int }: a shared I²C bus plus two GPIO pins each.

Add-on boards

Display: 16×9 colour LEDs (plug into E1)

var g = require("Smartibot-display").connect(s.E1);
g.drawString("Hi"); g.flip();

Uses the standard Graphics API. Call g.flip() to show what you drew.

Distance: laser + gesture sensors (plug into E1)

var d = require("Smartibot-distance").connect(s.E1);
d.getLeft(); d.getRight(); d.getGesture();

Uses VL53L0X time-of-flight and APDS9960 gesture sensors.

Anything else

E1/E2 are plain I²C ports, so many Espruino sensor modules work once wired.

Explore it yourself

Type these in the IDE console:

Object.keys(require("Smartibot")) // list functions
require("Smartibot").setServo     // show its code
NRF.getBattery()                  // battery voltage
process.memory()                  // free memory
  • Press Tab in the console to autocomplete.
  • Build something in Blockly, then switch to code view to see the JS it makes.
  • Anything in the Espruino reference runs on the robot, e.g. NRF.* for Bluetooth.
